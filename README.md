# Diario de Viaje 🌍✈️

Repositorio oficial del proyecto **DiarioDeViaje**, un diario de viajes estructurado y desarrollado como asignación de software utilizando control de versiones con Git y documentación en Markdown.

## 📋 Descripción del Proyecto
Este proyecto recopila descripciones, recomendaciones, registros fotográficos y detalles de múltiples destinos emblemáticos alrededor del mundo, manteniendo un historial de cambios limpio y profesional basado en ramas independientes y confirmaciones estructuradas.

## 🗺️ Destinos Incluidos
El diario cuenta con entradas detalladas para los siguientes destinos:
- **París** (Francia)
- **Roma** (Italia)
- **Tokio** (Japón)
- **Sídney** (Australia)
- **Nueva York** (Estados Unidos)
- **Londres** (Reino Unido)
- **Berlín** (Alemania)
- **Río de Janeiro** (Brasil)
- **Dubái** (Emiratos Árabes Unidos)
- **Ciudad de México** (México)

🛠️ Tecnologías y Estándares
 * Markdown: Formato de texto ligero utilizado para estructurar las guías de viaje.
 * Git & GitHub: Herramientas de control de versiones y colaboración remota mediante ramas (branches) y fusiones (merges).
 * Conventional Commits: Estándar de mensajes de confirmación (ej. feat:, docs:).
🚀 Cómo clonar y visualizar el proyecto
 * Clona el repositorio en tu computadora local:
   git clone [https://github.com/Olivertus/DiarioDeViaje.git](https://github.com/Olivertus/DiarioDeViaje.git)

 * Entra a la carpeta del proyecto:
   cd DiarioDeViaje

 * Explora la carpeta entradas/ con tu editor de código favorito (como Visual Studio Code) para leer el contenido de los archivos .md.
